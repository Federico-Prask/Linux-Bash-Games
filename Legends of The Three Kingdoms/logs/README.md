# logs —— 日志区（滚动，总量 ≤ 100KB）

本目录存放**过程性日志**：逐轮扫描记录、实现修正经过、已完成的待办台账等。
**长期参考资料不放在这里**，放 `docs/`（资料区）——今后新增资料也一律存 `docs/`。

## 规则（用户 2026-10-04 指示）

1. **`logs/` 整目录体积不超过 100KB**（由测试 `docs/logs_size_within_limit` 自动校验；超限即测试失败）。
2. 日志文件按 `YYYY-MM-DD_主题.md` 命名，最新追加内容写进当月文件。
3. 超过 100KB 时：压缩旧日志（合并同题材、删去过期细节），**只保留仍有价值的结论摘要**；被压缩掉的细节若属资料性质，移入 `docs/`。
4. 待办完成后，把该条的“完成结论 + 提交号”追加到 `completed_todo.md`，并从 `TODO.md` 删除（`TODO.md` 只留未完成项）。
