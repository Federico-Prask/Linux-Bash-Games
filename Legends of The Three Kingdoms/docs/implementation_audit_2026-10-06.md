# 实现级复核台账（2026-10-06，进行中）

范围：把 `Skill::getDescription()`（= 官网申明文本，124 名已逐字核对）与引擎**实现**逐条对照，
把“实现与申明文本的差异”逐一申明并解决。本文件记录本轮发现、处置与测试。

方法：
1. **自动不变式**（全 253 技能覆盖）：
   - `audit/tag_keywords_match_description`：描述里的类型关键词（锁定技/限定技/觉醒技/主公技/转换技/持恒技）
     必须与 `SkillTag` 完全一致（“非锁定技”等否定用法不计）。
   - `audit/charge_skill_declared_start_and_cap_match`：声明“蓄力技（x/y）”者，开局实际蓄力 = x / 上限 = y。
   - 技能登记≠实现：全部 253 技能均有实现，无“技能资料待核对。”占位。
2. **定向深查**：对无测试覆盖的技能、复杂技能、既有“待复核”清单逐条读码对照文本。
3. 发现差异 → 改实现（或补标签）→ 加正/反例测试 → 更新本台账。
